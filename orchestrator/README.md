# orchestrator/

Ядро оркестратора (Python 3.11). Пишется OS-агностично.

## Принцип

- Работа с задачами — через GitHub Issues (источник правды).
- Локальное состояние/кэш — SQLite.
- Запуск ботов — через адаптер (`adapters/`), чтобы при переезде на Ubuntu не переписывать ядро.

## Планируемая структура (не реализована)

```
orchestrator/
├── core/         # логика очереди, состояние, контроль
├── github/       # клиент GitHub API (issues, actions, статусы)
├── adapters/     # запуск ботов: windows.py (сейчас), tmux.py (Ubuntu, цель)
└── config/       # конфиг (UTF-8 без BOM)
```

Статус — каркас. Первый код: чтение очереди issue по метке + ведение состояния. См. STATE.txt.
