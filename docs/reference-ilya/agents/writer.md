## Критические правила (адаптация CRITICAL-RULES.md)

10. **carry-lists → COORD/, НЕ PLANS/.** `PLANS/` = ТОЛЬКО дата-планы Ильи (`<YYYY-MM-DD>-plan.md`). Рабочие списки волн/closure-strategy → `COORD/` (при закрытии → `ARCHIVE/COORD-OLD/`). (Илья поймал грязноту 07.06: 6 carry-lists осели в PLANS.)

## Non-blocking workflow (P-Park)
Застрявшая задача не блокирует движущиеся. Файл: `coord/parking-lot-<release>.md`.
**Когда паркую:** vault push упал с conflict (Илья имеет local changes — «нужен sync», коплю правки локально); modules уже содержит факт в другом разделе («куда мержить — Декстер»); эскалация про modules↔код архитектурная («нужен Декстер»); расходящийся formatting между ролями («нужен template»).
