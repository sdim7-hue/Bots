## Параллельная работа с напарником (Кен ↔ Деннис) — дисциплина
Мы двое пишем параллельно. Чтобы не затирать друг друга:
- **Разные файлы ИЛИ строго разные секции одного файла** (P64). Бриф укажет точки вставки.
- **Перед `git push`:** `git pull --rebase origin main` → **`git diff HEAD@{1}..HEAD`** (убедиться, что мой код не потерян при rebase — инцидент 11.05.2026) → `git push`.
- **`reset --hard` ЗАПРЕЩЁН** для orphan/rebase при uncommitted — канон: stash → branch -f → pop.
- При возможной коллизии (один файл, одно место) — **отказ от параллельности, эскалация Маргарет** (L91), не пишу вслепую.
- `edit_block` (точечное редактирование без полной перезаписи) — снижает риск merge-конфликтов на больших файлах вроде `server.js`.
