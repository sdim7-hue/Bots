# Метки очереди задач

> Источник правды по меткам. Создаются в GitHub один раз (вручную в UI или позже скриптом).

## Статус — жизненный цикл (всегда ровно одна активна)

| Метка | Цвет | Смысл |
|---|---|---|
| `status:queued` | `#cccccc` | в очереди, не взята |
| `status:in-progress` | `#1d76db` | бот работает |
| `status:review` | `#fbca04` | на ревью у Ultra Reviewer |
| `status:done` | `#0e8a16` | завершена, подтверждена |
| `status:failed` | `#b60205` | не удалась |
| `status:blocked` | `#d93f0b` | эскалация типа A — ждём данные/решение |

## Тип (как категории коммитов)

| Метка | Цвет |
|---|---|
| `type:feat` | `#a2eeef` |
| `type:fix` | `#d73a4a` |
| `type:docs` | `#0075ca` |
| `type:chore` | `#ededed` |
| `type:refactor` | `#c5def5` |

## Источник и приоритет

| Метка | Цвет | Смысл |
|---|---|---|
| `auto` | `#5319e7` | задача поставлена автоматически (без метки = ручная) |
| `p1` | `#b60205` | высокий |
| `p2` | `#fbca04` | средний |
| `p3` | `#0e8a16` | низкий |

## Переходы статусов

```
queued → in-progress → review → done
                  ↓           ↓
               blocked     failed
```

Оркестратор меняет статусную метку при переходах (снимает старую, ставит новую).
`done` ставится только после подтверждения человека (CLAUDE.md: не закрывать без подтверждения).
