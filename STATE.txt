ЧТО ЭТО
-------
Система оркестрации Claude Code ботов. Цель — параллельное выполнение задач
с автоматической постановкой и контролем. Участники: человек -> Claude-оркестратор
-> боты Claude Code -> GitHub.

КУРС (утверждён 2026-05-30)
---------------------------
- Ядро OS-агностично: GitHub Issues = очередь задач, GitHub Actions = автоконтроль,
  Python-оркестратор. (вариант C+B)
- Запуск ботов — заменяемый адаптер. Сейчас Windows, целевая среда — Ubuntu + tmux
  (схема как у Ильи: N кодеров + Ultra Reviewer + Диспетчер, автономный цикл).
- Переход на Ubuntu плавный: dual-boot -> при успехе Windows удаляется; плюс второй ПК.

ГДЕ ОСТАНОВИЛИСЬ (2026-05-30)
--------------------------
