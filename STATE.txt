Bots — оркестратор Claude Code. Источник правды «как сейчас». Читать первым.
Обновлено: 30.05.2026.

== Что это ==
Цепочка: человек → Claude-оркестратор → боты Claude Code → GitHub.
Задачи = GitHub Issues с метками статуса. Цель — параллельная работа с
автоконтролем. Курс OS-агностичный: Windows сейчас → Ubuntu/tmux потом (ADR-002).

== Состояние ==
- Каркас: README, STATE, CLAUDE.md, docs/ (architecture; decisions ADR-001..004),
  .github/ISSUE_TEMPLATE. Метки (15) + шаблон-бриф из 5 блоков.
- orchestrator/ (Python 3.11, только stdlib):
  - core.py — модель Task + состояние в SQLite (StateStore).
  - config.py — токен (env/конфиг Claude), OWNER/REPO, путь к БД.
  - github_client.py — REST-клиент: list_issues_by_label, get_issue,
    set_status (меняет только status:*), add_comment; _request с GET/POST/PATCH.
  - adapters/local.py — run_bot(brief, cwd, timeout) -> BotResult: запуск
    `claude -p`, stdin=DEVNULL, захват UTF-8, таймаут; кроссплатформенный поиск claude.
  - __main__.py — команды: list, run-bot (--message/--file --timeout),
    run-next (автоцикл).
- Claude Code CLI 2.1.158 авторизован (Claude Team, Opus 4.8); headless `claude -p` работает.
