Обновлено: 30.05.2026.

== Что это ==
Цепочка: человек → Claude-оркестратор → боты Claude Code → GitHub.
Задачи = GitHub Issues с метками статуса. Цель — параллельная работа с
автоконтролем. Курс OS-агностичный: Windows сейчас → Ubuntu/tmux потом (ADR-002).

== Состояние ==
- Каркас: README, STATE, CLAUDE.md, docs/ (architecture; decisions ADR-001..004),
  .github/ISSUE_TEMPLATE.
- Метки (15) + шаблон-бриф из 5 блоков — готовы.
- orchestrator/ (Python 3.11, только stdlib):
  - core.py, github_client.py, config.py — чтение очереди status:queued +
    состояние в SQLite. (#1, done)
  - adapters/local.py — run_bot(brief, cwd, timeout) -> BotResult: запуск
    `claude -p`, stdin=DEVNULL, захват UTF-8, таймаут -> TimeoutError;
    кроссплатформенный поиск claude (shutil.which + %APPDATA%\npm). (#2, review)
  - __main__.py — команды `list` и `run-bot --message/--file --timeout`.
- Claude Code CLI 2.1.158 установлен и авторизован (Claude Team, Opus 4.8);
  headless `claude -p` работает.
