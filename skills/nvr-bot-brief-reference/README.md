# nvr-bot-brief — Custom Skill для TESLATEL Cloud NVR

Это первый кастомный скилл проекта. Создан 02.05.2026 в ~03:00 ночи.

## Что это

Скилл `nvr-bot-brief` инкапсулирует **проверенный паттерн отправки брифов ботам Claude Code** в проекте TESLATEL Cloud NVR. После установки Claude автоматически применяет правильный формат, технику доставки (load-buffer/paste-buffer вместо send-keys), правила P50, и стандартный отчётный шаблон.

## Файлы

```
nvr-bot-brief/
├── README.md                    ← этот файл
├── SKILL.md                     ← главный файл скилла (frontmatter + body)
└── examples/
    ├── light-theme-fix.md       ← бриф на CSS-фикс одного класса
    ├── multi-file-feature.md    ← бриф на новый раздел / multi-file feature
    └── diagnostic-only.md       ← бриф на read-only диагностику
```

## Как установить

**Вариант A (рекомендуется когда подтвердим что работает):**

1. Запаковать папку `NVR-2026/skills/nvr-bot-brief/` в zip
2. На claude.ai → Settings → Capabilities → Skills → "+ Add Skill"
3. Загрузить zip
4. Включить для нужных контекстов (Claude.ai chats / API)

**Вариант B (использовать как референс прямо сейчас, без установки):**

Просто хранить эту папку в vault. Перед началом сессии Claude может прочитать `SKILL.md` через obsidian MCP — это даст почти ту же пользу что и установленный скилл, разве что без автоматического срабатывания на триггеры.

## Что делать после установки

1. Протестировать на хвосте плеера 12ч/6ч/2ч/30м (на 02.05 в плане)
2. Если бот стабильно начинает использовать правильную технику без напоминаний — оставить как есть
3. Если бот игнорирует или путает паттерны — итерировать `SKILL.md` (часть `description` особенно важна — она определяет когда скилл триггерится)

## Триггеры (из description)

Скилл активируется когда Илья говорит:
- "отправь бриф боту"
- "дай задачу боту 0.0" / "боту 0.1"
- "пусть бот сделает"
- "запусти на боте"

И НЕ активируется на:
- Документационные задачи (vault-правки, никакого кода)
- Read-only диагностику самим Claude
- Прямые pull на DEV1/MaMaison

## История версий

- **v1.0 (02.05.2026)** — первая версия. Создана по итогам марафона 30.04→01.05 где паттерн брифа сложился и стабилизировался. Ключевые источники: техника tmux load-buffer выяснилась из L57+, правила P50 (DEV2 single writer) от 25.04, формат отчёта эволюционировал в течение апреля.

## Notes from creation session

Создан в ночь 01→02.05.2026. Илья попросил один скилл сначала чтобы протестировать процесс и формат. Решено что три примера разной сложности (CSS-fix / multi-file / diagnostic) лучше покрывают пространство задач чем один универсальный пример.

Скилл сознательно **не дублирует** содержимое vault (PRINCIPLES.md, BOT_ORCHESTRATION.md). Вместо этого он ссылается на них в секции "Reference". Это важно потому что vault обновляется, а скилл фиксированный — дублирование привело бы к расхождению со временем.
