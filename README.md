# Bots

Оркестрация Claude Code ботов: задачи ставятся и контролируются автоматически, исполняются параллельно. Связывает четырёх участников — **человек → Claude-оркестратор → боты Claude Code → GitHub**.

## Идея

- **Источник правды задач — GitHub Issues.** Задача = issue с меткой статуса (`queued` / `in-progress` / `review` / `done` / `failed`).
- **Автоконтроль — GitHub Actions + опрос API** оркестратором (коммиты, PR, статусы проверок, закрытие issue).
- **Исполнители — боты Claude Code.** Оркестратор код не пишет: формулирует брифы и контролирует результат.
- **OS-агностичность.** Ядро (оркестратор + Issues) не зависит от ОС. Запуск ботов вынесен в заменяемый адаптер: сейчас Windows, целевая среда — Ubuntu + tmux (схема как у Ильи).

## Состояние

См. `STATE.txt` — источник правды «как сейчас». Читать первым при входе в проект.

## Документы

- `STATE.txt` — текущее состояние и где остановились.
- `CLAUDE.md` — инструкции для ботов-кодеров (читают при старте в репозитории).
- `docs/architecture.md` — роли, цикл работы, эскалации.
- `docs/decisions.md` — журнал архитектурных решений (ADR).

## Стек

Python 3.11, GitHub Issues + Actions, SQLite (локальная очередь/состояние). Без сторонних оркестраторов и тяжёлой инфраструктуры на старте.
